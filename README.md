# Proyecto Finca - Grupo 12

## 1. Descripción del proyecto

Este proyecto fue desarrollado como parte del Taller Grupal de la asignatura **Programación 3**. Su propósito es configurar un entorno profesional de desarrollo utilizando Java, Maven, Git, GitHub y JUnit 5.

El proyecto contiene la clase `Parcela`, que permite registrar el código de una parcela agrícola y calcular su área en metros cuadrados a partir de las hectáreas ingresadas.
